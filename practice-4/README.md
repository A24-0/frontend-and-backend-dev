# Практическое занятие 4 — API + React

Интернет-магазин товаров: бэкенд (Express) и фронтенд (React), связанные в одну систему.

## Задание по методичке

Два приложения — React и Express — связанные в единую систему (интернет-магазин). Тематика на ваше усмотрение. Не менее **10 товаров**. Карточка товара: название, категория, описание, цена, количество на складе (опционально: рейтинг, фото).

## Структура

- `server/` — Express API (порт 3000), CRUD по товарам, CORS для клиента.
- `client/` — React (Vite), порт 3001.

## Как запустить и проверить

1. **Сервер:**  
   `cd practice-4/server && npm install && npm start`  
   Должен вывести: `Сервер запущен на http://localhost:3000`, товаров 10.

2. **Клиент:**  
   `cd practice-4/client && npm install && npm run dev`  
   Откройте http://localhost:3001 — список товаров, добавление/редактирование/удаление.

3. Проверка: на главной отображаются 10 товаров, кнопки «Редактировать» и «Удалить» работают, форма «+ Добавить товар» создаёт новый товар.
