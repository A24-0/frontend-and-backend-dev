# Практическое занятие 6 — Подготовка к контрольной работе №1

Контрольная работа №1 — это **результат выполнения Практических заданий 1–5**.

## Задание по методичке

1. **Протестировать работоспособность** реализованного приложения (практики 1–5).
2. **Подготовить корректный README.md** с описанием проделанной работы (см. корневой README репозитория).
3. **Проверить, что репозиторий открытый** (доступен по ссылке без авторизации).

Ответ на задание — ссылка на репозиторий (СДО: Задания текущего контроля → Контрольная работа №1).

---

## Как проверить работоспособность

| Практика | Что проверить |
|----------|----------------|
| **1** | Открыть `practice-1/index.html` в браузере — отображается карточка товара. |
| **2** | `cd practice-2 && npm install && npm start` → в браузере или Postman: GET http://localhost:3000/products — JSON с товарами. |
| **3** | В Postman: ≥3 запроса к API из П2; ≥5 запросов к выбранному внешнему API. Скриншоты в `practice-3/screenshots/`. |
| **4** | Запустить `practice-4/server` (порт 3000) и `practice-4/client` (порт 3001). В браузере http://localhost:3001 — список товаров, добавление/редактирование/удаление. |
| **5** | Запустить `practice-5/server` (порт 3000). Открыть http://localhost:3000/api-docs — Swagger UI, отправить тестовый запрос (например, GET /api/products). Фронт — как в П4. |

Краткие команды для проверки П4 и П5 см. в README в папках `practice-4` и `practice-5`.
