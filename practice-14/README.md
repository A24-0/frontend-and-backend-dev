# Практика 14 — Web App Manifest

Реализовано расширение приложения PWA-манифестом и кэшированием манифеста/иконок.

## Что сделано по ТЗ
- `manifest.json` с обязательными полями.
- Набор PNG-иконок (минимум 3).
- Подключение `<link rel="manifest">` в `index.html`.
- Мета-теги для мобильных платформ.
- Обновлённый `sw.js` с кэшированием `manifest.json` и иконок.
