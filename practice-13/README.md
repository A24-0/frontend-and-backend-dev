# Практика 13 — Service Worker

Реализовано приложение заметок с сохранением в `localStorage` и офлайн-доступом через Service Worker.

## Требования из ТЗ
- Просмотр списка заметок.
- Добавление новой заметки.
- Хранение данных в `localStorage`.
- Регистрация Service Worker.
- Кэширование статики и работа офлайн.

## Запуск
Можно открыть через любой локальный сервер, например:

```bash
cd practice-13
python3 -m http.server 4173
```

Открыть `http://localhost:4173`.
