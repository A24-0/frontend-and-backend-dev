# Практическое занятие 5 — Расширенный REST API (Swagger)

К заданию из Практики 4 подключены **swagger-jsdoc** и **swagger-ui-express**. Описаны схема товара (Product) и все CRUD-операции (GET, POST, GET/:id, PATCH/:id, DELETE). Документация доступна по адресу **/api-docs** и работает в интерактивном режиме.

## Задание по методичке

Доработать задание из П4: подключить swagger-jsdoc и swagger-ui-express, описать JSDoc-аннотациями схему и все CRUD. Убедиться, что документация доступна по **/api-docs** и можно отправить тестовый запрос.

## Как запустить и проверить

1. **Сервер (здесь же Swagger):**  
   `cd practice-5/server && npm install && npm start`

2. Откройте в браузере: **http://localhost:3000/api-docs**  
   — отобразится Swagger UI со списком эндпоинтов. Нажмите «Try it out» у любого метода (например, GET /api/products), затем «Execute» — должен вернуться список товаров.

3. **Фронтенд** — как в Практике 4: запустите клиент из `practice-4/client` (npm install && npm run dev) и откройте http://localhost:3001. Он обращается к API на порту 3000, поэтому при запущенном сервере из practice-5 всё будет работать.

Итог: в П5 только бэкенд с Swagger; фронт общий с П4.

Ответ на задание — ссылка на репозиторий (СДО: Практические занятия 5–6).
